# ArthurBrioche Cadre

## How do I install these formulae?

`brew install arthurbrioche/cadre/<formula>`

Or `brew tap arthurbrioche/cadre` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "arthurbrioche/cadre"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
